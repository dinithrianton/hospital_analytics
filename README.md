# hospital_analytics

This is a Hospital BI analysis data querying and visualization project based on the LinkedIn Learning course: Analyze Patient Encounters and Costs with MySQL. Attached are a printed copy of the objectives of the analysis and the corresponding SQL queries, the SQL code file, and the following Tableau Public link to two insightful dashboards visualizing the queried data. 

https://public.tableau.com/views/HospitalAnnualPerformanceReport/Procedures?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

Tools utilized: SQLite, DB Browser for SQLite, Tableau Desktop Public Edition
