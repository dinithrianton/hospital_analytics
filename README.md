# hospital_analytics

This is a BI analysis data querying and visualization portfolio project to serve the Annual Performance Report of the Massachusetts General Hospital, based on the LinkedIn Learning course: Analyze Hospital Patient Encounters and Costs with MySQL (Guided Project) by Maven Analytics. Attached are the analysis objectives, the SQL code file, the following Tableau Public link to dashboards visualizing the queried data, along with printed copies of the queries and visualizations as previews. 

https://public.tableau.com/views/MassachusettsGeneralHospitalAnnualPerformanceReport/AnnualEncounters?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

Tools utilized: SQLite, DB Browser for SQLite, Tableau Desktop Public Edition
